SCENTORY V64 — November catalogue and poster update

This release adds Liquid Brun Limited Edition and Lattafa Angham EDP with their supplied Scentory posters, current regular decant prices, and complete perfume profiles. It also updates the regular prices for Liquid Brun by French Avenue (EDP) and the existing Ameer Al Oudh Intense Oud listing, and marks Yusuf Bhai - Men 212 out of stock.

FULL MASTER ZIP
Use SCENTORY_V64_FULL_MASTER.zip for a complete website replacement / full repository baseline.

UPDATED-ONLY ZIP
Use SCENTORY_V64_ONLY_UPDATES_FROM_V55.zip when updating a live V55 baseline. It contains the accumulated V56–V64 changed files, not a complete copy of every original V55 asset.

INSTALLATION
1. Extract the selected ZIP.
2. Upload the extracted files directly into the website / GitHub repository root.
3. Replace files with matching names when prompted.
4. Do not upload the ZIP itself and do not place the extracted files inside a new nested folder.

The existing temporary Scentory sunset theme is preserved with its original V62 expiry; this update does not restart its timer.
