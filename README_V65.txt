SCENTORY V65 — Compact 3D Featured Carousels

WHAT CHANGED
- New to Scentory now shows the approved 12 most recently added perfumes in a compact 3D coverflow carousel.
- Best Selling now shows the approved 12 customer favourites in the same compact 3D card style.
- The centered card is larger and elevated; neighboring cards tilt back in perspective. Customers can swipe, use the arrows, or use keyboard arrow keys.
- New arrivals are data-driven. Each genuinely new perfume should receive a newArrivalSequence value higher than the current maximum in perfumes.json. Price or poster edits to existing perfumes do not change their arrival sequence. The homepage automatically selects the highest 12 sequence values; when a 13th genuine new perfume is added, the oldest entry drops out. The carousel itself does not need a manual ID-list edit.

ZIP CHOICES
1. SCENTORY_V65_FULL_MASTER.zip — complete website repository, based on V64 plus this V65 update.
2. SCENTORY_V65_ONLY_UPDATES.zip — only the files changed or added in V65 relative to V64. It does not include the historical V56–V64 update files.

INSTALLATION
- For a full replacement, extract the Full Master ZIP and upload all extracted contents directly to the website root.
- For an existing V64 site, extract the Only Updates ZIP and upload its contents directly to the website root, replacing matching files.
- Do not upload the ZIP itself and do not put the extracted files inside a new folder.

The full master includes the complete V64 site and the current V65 changes. The only-updates archive contains exactly the current release files listed in CHANGE_MANIFEST_V65.json.
